Терминал MacOS

  • ls - используется для отображения списка файлов и директорий в текущей директории. Она предоставляет информацию о содержимом директории и позволяет настраивать вывод с помощью различных опций.

  • cd - используется для изменения текущей рабочей директории. Это одна из наиболее часто используемых команд в терминале, позволяющая пользователям перемещаться по файловой системе.

  • pwd - отображает полный путь текущей рабочей директории. Это полезно для проверки, где вы находитесь в файловой системе в данный момент.

  • mv - используется для перемещения или переименования файлов и директорий. Она позволяет изменить расположение файлов или их имена.

  • mkdir - используется для создания одной или нескольких директорий (папок) в текущем каталоге.
